# K-TOP ENG 랜딩페이지

등급: A / 상태: 배포 준비 완료

- 무엇 : 에어컨 설치·A/S·세척·유지보수 업체 K-TOP ENG의 원페이지 랜딩사이트
- 누가 씀 : 친구(K-TOP ENG 대표)가 GitHub Pages로 배포해 실제 고객에게 공개
- 스택 : 정적 HTML 1파일 + 이미지 폴더 (서버·빌드 도구 없음, 그대로 GitHub Pages에 올리면 동작)
- 데이터 : 저장 없음(문의 폼은 `sms:` 링크로 문자 앱을 여는 방식) — 백업 대상 아님
- 배포 : GitHub Pages — 이 폴더(`index.html` + `assets/`)를 레포 루트에 그대로 올리고 Pages 설정만 켜면 됨

## 배포 방법 (요약)
1. GitHub에 새 레포 생성 (예: `ktop-eng-site`)
2. 이 폴더의 `index.html`과 `assets/` 폴더를 레포 루트에 그대로 업로드
3. 레포 Settings → Pages → Branch를 `main`(또는 배포 브랜치)으로 설정
4. `https://<사용자명>.github.io/<레포명>/` 로 접속 확인

## 원본 대비 이번에 바꾼 것
- **이미지 21장을 base64로 HTML에 통째로 박아넣던 구조 → `assets/img/` 폴더의 압축된 JPEG 파일로 분리.** 파일 전체 용량 128MB → 2.6MB (약 97% 감소). base64였을 때는 이미지가 다 안 끝나면 글자 한 줄도 안 보이는 구조였는데, 이제 일반적인 이미지 태그라 페이지 텍스트가 먼저 뜨고 이미지는 순서대로 채워짐(`loading="lazy"`는 원본 그대로 유지)
- 이미지는 실제 표시 크기 기준으로 리사이즈(1200~1600px) + JPEG 품질 78~85%로 압축. 화면상 화질 차이는 거의 없음(직접 스크린샷 대조함)
- 로고 원본이 2304×1536 사진 해상도였던 것도 480px로 축소 → 2.22MB → 8KB
- 파비콘 세트(`favicon.ico`, 192px PNG) + `apple-touch-icon.png` 추가 — 원래 브라우저 탭 아이콘이 없었음
- `og:image`, `og:type`, `twitter:card` 메타 추가 — 카카오톡/문자로 링크 공유 시 미리보기 썸네일이 뜨도록. **다만 `og:image`가 지금은 상대경로라 실제 배포 도메인이 정해지면 절대경로(`https://.../assets/img/...`)로 바꿔야 크롤러가 인식합니다.**
- 문의 폼 `성함`·`연락처` 필드에 `required` 추가 — 원래는 빈 값으로도 제출돼서 "성함: -, 연락처: -" 같은 문자가 갈 수 있었음
- `LocalBusiness` 구조화 데이터(JSON-LD) 추가 — 검색엔진이 업체명·전화번호·주소를 더 잘 인식하도록 돕는 용도, 화면에는 안 보임
- 이전 세션이 남긴 `<meta name="standalone-assets" content="embedded-data-uri">` 문구가 이제 사실과 달라져서 `external-assets-img-folder`로 갱신

## 요청 범위 밖이라 손대지 않은 것 (이전 리뷰에서 안내드린 내용)
- 사업자등록번호 미표기, 큐레어 브로셔 가격 최신성, 주소 상세표기 여부 — 사업 정보라 직접 확인 후 텍스트만 고치면 됨
- PC 사용자용 문의 폼 대안(현재는 `sms:` 링크 전용) — 이메일 병행 등은 추가 기능 작업이라 별도 요청 시 진행

## 텍스트 줄바꿈·이미지 겹침 수정 (2차)
- 한글 문장이 단어 중간에서 끊기던 문제 → `body`에 `word-break:keep-all` 적용, 이제 띄어쓰기 단위로만 줄바꿈됨 (히어로 제목, work-caption, contact 제목 등 전역 적용)
- 큐레어 섹션·갤러리 섹션 제목이 "에어, 리에 더, 해," 식으로 극단적으로 깨지던 것 → 원인은 장식용 라벨(`::before` 가상요소)이 실수로 그리드 레이아웃 안에 끼어들어가 제목을 215px 좁은 칸으로 밀어넣은 CSS 버그였음. 해당 라벨을 `position:absolute`로 그리드 밖으로 빼서 원래 의도대로 좌측 상단 코너 라벨로 고정
- "공기질 관리 상담" 카드에서 본문 텍스트가 하단 이미지와 겹치던 문제 → 이미지 있는 카드만 높이를 늘리고(380→480px) 이미지 비율을 줄여(45%→34%) 텍스트 공간 확보
